# アクティブ判例集 (Active Rules)

AIレビュアー (`pr_reviewer.py`) が読み込む判例集。
- **このファイルはupsert運用**: 同じトピックに新しい判断が下されたら上書きする（行数を増やさない）
- **証跡は `judgments.md`**: 全履歴はそちらに残す。このファイルは「現在有効な判断」のみ
- **更新タイミング**: `judgments.md` に追記するとき、同時にこのファイルの該当トピックを更新する

---

## [DX-001] Draft PR の扱い

**トピック**: Draft PR に対するAI検閲のブロック可否  
**判断**: Draft PR はレビューするがブロックしない。Ready for Review 時点から厳格にブロックする  
**理由**: Draft は `main` にマージ不可のため本番隔離が物理的に担保されている。`[skip ai]` のようなバイパスはIPO監査の職務分掌・証跡確保に反する  
**最終更新**: 2026-05-07
